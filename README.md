Solmara Heat — a complete open-world crime game in the spirit of GTA 6, playing offline in a desktop browser. Explore the sun-soaked coastal city of Solmara on foot and by car: traffic and pedestrians, cars to steal and drive, a wanted level with police chases, four story missions (Fresh Wheels, Hot Wheels, The Pickup, The Solmara Job), combat, a HUD with a minimap, a start screen and a save. Everything is original — the city, characters, names, art and sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network, no dependencies: plain static files under game/.
